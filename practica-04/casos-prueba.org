* Implementación Original del Sistema

Dado el modelo del sistema de estacionamiento, se plantearán las pruebas necesarias para verificar que el comportamiento de la implementación original del sistema sea el esperado por el modelo del mismo.

#+latex: \vspace{\baselineskip}

En caso de que la implementación original del sistema no pase las pruebas planteadas, modificaremos el código para que este último tenga el comportamiento esperado por el modelo del sistema.

#+latex: \vspace{\baselineskip}

#+BEGIN_EXPORT latex

\begin{lstlisting}[style=practica]
    ...

    TARIFA_BOLETO_PERDIDO = 300.0

    def calcular_total(self, minutos: int, tipo_cliente: str = "normal",
                       boleto_perdido: bool = False) -> float:
        """
        Calcula el total a pagar de acuerdo con el modelo de la práctica.

        Nota para el alumno:
	trate esta implementación como un sistema que debe verificarse.
	No asuma que todo lo que hace el código es correcto.
	"""
    
        if minutos < 0:
            raise ValueError("Los minutos no pueden ser negativos")


        if tipo_cliente not in ("normal", "frecuente"):
            raise ValueError("Tipo de cliente no válido")


        if boleto_perdido:
            total = self.TARIFA_BOLETO_PERDIDO
            

        elif minutos < 15:
            total = 0.0
            

        elif minutos <= 60:
            total = 20.0

	
        else:
            horas_adicionales = (minutos - 60) // 60
            total = 20.0 + (horas_adicionales * 15.0)

	
        if tipo_cliente == "frecuente":
            total *= 0.90

        return round(total, 2)

    ...
\end{lstlisting}

* Reglas del Sistema: Ticket de Estacionamiento

Las reglas del Sistema de Ticket de Estacionamiento son:

#+BEGIN_EXPORT latex
\begingroup
\setlength{\parskip}{0.85em}
#+END_EXPORT

*R1.* Los minutos deben ser un número entero mayor o igual que 0.

*R2.* Los tipos de clientes válidos son:

- *"normal"*
- *"frecuente"*

*R3.* Si el boleto está perdido, el costo final es de $300.00, sin importar los minutos ni el tipo de cliente.

*R4.* Si los minutos son 0, el costo es $0.00

*R5.* De 1 a 15 minutos, el costo es $0.00

*R6.* De 16 a 60 minutos, el costo es de $20.00

*R7.* Después de 60 minutos se cobran $20.00 por la primera hora y $15.00 por cada hora adicional *iniciada*.

*R8.* Un cliente *"frecuente"* recibe un 10% de descuento sobre el costo calculado, excepto cuando perdió el boleto.

*R9.* El costo nunca puede ser negativo.

*R10.* Si los minutos son negativos, el sistema debe lanzar un error.

*R11.* Si el tipo de cliente no es válido, el sistema debe lanzar un error.
