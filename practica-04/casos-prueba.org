* Código original

Código original a evaluar con una suit de pruebas, estas últimas deben sacarse del modelo del Sistema de Ticket estacionamiento, no del Código original.

#+latex: \vspace{\baselineskip}

#+BEGIN_EXPORT latex

\begin{lstlisting}[style=practica]
# Tarifa del boleto perdido.
TARIFA_BOLETO_PERDIDO = 300.0

def calcular_total(self, minutos: int, tipo_cliente: str = "normal",
                   boleto_perdido: bool = False) -> float:
    """
    Calcula el total a pagar de acuerdo con el modelo de la práctica.

    Nota para el alumno:
    trate esta implementación como un sistema que debe verificarse.
    No asuma que todo lo que hace el código es correcto.
    """
    # Entrada Invalida: Minutos Negativos.
    if minutos < 0:
        raise ValueError("Los minutos no pueden ser negativos")

    # Entrada Inválida: Tipo de cliente no reconocido.
    if tipo_cliente not in ("normal", "frecuente"):
        raise ValueError("Tipo de cliente no válido")

    # Si el boleto está perdido -> $300.00
    if boleto_perdido:
        total = self.TARIFA_BOLETO_PERDIDO
            
    # Si permanece 15 minutos o menos -> $0.00
    elif minutos < 15:
        total = 0.0
            
    # Si permanece 60 minutos o menos -> $20.00
    elif minutos <= 60:
        total = 20.0
            
    # Si permanece mas de 60 minutos:
    # -> $20.00 la primera hora.
    # -> $15.00 cada hora iniciada.
    else:
        horas_adicionales = (minutos - 60) // 60
        total = 20.0 + (horas_adicionales * 15.0)

    # Si el cliente es "frecuente" aplicar el 10% de descuento.
    if tipo_cliente == "frecuente":
        total *= 0.90

    # Devolver el total redondeado con dos decimales.
    return round(total, 2)
\end{lstlisting}

* Reglas del Sistema: Ticket de Estacionamiento

Las reglas del Sistema de Ticket de Estacionamiento son:

#+BEGIN_EXPORT latex
\begingroup
\setlength{\parskip}{0.85em}
#+END_EXPORT

*R1.* Los minutos deben ser un número entero mayor o igual que 0.

*R2.* Los tipos de clientes válidos son:

- *"normal"*
- *"frecuente"*

*R3.* Si el boleto está perdido, el costo final es de $300.00, sin importar los minutos ni el tipo de cliente.

*R4.* Si los minutos son 0, el costo es $0.00

*R5.* De 1 a 15 minutos, el costo es $0.00

*R6.* De 16 a 60 minutos, el costo es de $20.00

*R7.* Después de 60 minutos se cobran $20.00 por la primera hora y $15.00 por cada hora adicional *iniciada*.

*R8.* Un cliente *"frecuente"* recibe un 10% de descuento sobre el costo calculado, excepto cuando perdió el boleto.

*R9.* El costo nunca puede ser negativo.

*R10.* Si los minutos son negativos, el sistema debe lanzar un error.

*R11.* Si el tipo de cliente no es válido, el sistema debe lanzar un error.

#+BEGIN_EXPORT latex

\begin{lstlisting}[style=practica]
# Arrange
@pytest.mark.parametrize(
    "minutos, esperado",
    [
                        # | Caso | Descripción                                |
        (10, 0.00),     # |  1   | Cliente "normal" con boleto pasó 10 min.   |
        (40, 20.00),    # |  2   | Cliente "normal" con boleto pasó 40 min.   |
        (1250, 320.00), # |  3   | Cliente "normal" con boleto pasó 1250 min. |
    ],
)
def test_cliente_Normal_con_Boleto(sistema, minutos, esperado):
    """
    Verifica el cobro calculado para un cliente "normal" con boleto
    dado un cierto tiempo en minutos.
    """

    # Act
    resultado = sistema.calcular_total(minutos, "normal", False)

    # Assert
    assert resultado == pytest.approx(esperado)
\end{lstlisting}

#+END_EXPORT

Al ejecutar las pruebas sin modificar el código original, falla el Caso 3 establecido en las pruebas; pero como comprobamos el resultado a obtener antes de ejecutar la prueba, concluimos que el código original falló la prueba y debemos corregirlo.

#+latex: \vspace{\baselineskip}

#+BEGIN_EXPORT latex

\begin{lstlisting}[style=practica]
...
    # Si permanece mas de 60 minutos:
    # -> $20.00 la primera hora.
    # -> $15.00 cada hora iniciada.
    else:
        horas_adicionales = (minutos - 60) // 60
        total = 20.0 + (horas_adicionales * 15.0)
...
\end{lstlisting}

#+END_EXPORT

#+latex: \vspace{\baselineskip}

Al observar el código original, debemos modificar el cálculo si el cliente permanece mas de 60 minutos, pues al dividir las horas adicionales, solo se toman en cuenta las horas completas que ya pasaron, pero falta contemplar las horas iniciadas, para compensar, debemos tomar el techo del resultado de la división:

#+latex: \vspace{\baselineskip}

#+BEGIN_EXPORT latex

\begin{lstlisting}[style=practica]
...
    # Si permanece mas de 60 minutos:
    # -> $20.00 la primera hora.
    # -> $15.00 cada hora iniciada.
    else:
        horas_adicionales = math.ceil((minutos - 60) / 60) # Modificación
        total = 20.0 + (horas_adicionales * 15.0)
...
\end{lstlisting}

#+END_EXPORT

Con este cambio, solucionamos un problema del código original y pasan las primeras tres pruebas de los primeros tres casos.
